Privacy policy

Opportunity Engine · Last updated 9 November 2026

Who uses the app

Opportunity Engine is a private tool. Only its developer signs in to it, with their own Google account. It is not offered to anyone else.

What data it accesses

With the developer's permission, the app uses the Google Ads API scope https://www.googleapis.com/auth/adwords to read keyword ideas and historical search volumes for the developer's own Google Ads account. It does not read campaign performance, billing data, contacts or any other personal data.

How the data is used and stored

  • Search volumes are used only to estimate demand for product ideas.
  • They are stored on the developer's own computer. They are not sold, shared or sent to any third party.
  • The OAuth token is stored on the same computer with owner-only file permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Access can be removed at any time at myaccount.google.com/permissions. Stored data is deleted by removing the app's local files.
